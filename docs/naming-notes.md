# Naming Notes

## Legwork / Leg Work

Current-use screen as of July 4, 2026: do not use `Legwork` as the main brand without proper trademark counsel.

Reasoning:

- Exact-name software and app usage already exists.
- `legwork.com` is tied to an established dental patient engagement product.
- A USPTO record exists for `LEGWORK`.
- App Store results include exact-name consumer apps.
- The word is common enough that SEO and distinctiveness would be weak.

Product read:

- Good semantic fit for a parlay feature because parlays have legs.
- Better as a feature name, internal codename, or campaign phrase.
- Not clean enough for the consumer-facing app/company name.

Cleaner candidates to keep exploring:

- `Event Stack`
- `ClearIf`
- `Signal Basket`
- `Condition Met`
- `Thesis Ticket`
